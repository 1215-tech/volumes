The server, in a sense, is the heart of the household. It can do everything from hosting game servers to serving as ones personal library. If you set it up in a certain way, it can even serve as a second brain of sorts. All of that said, it's quite ironic that my server has always been made out of old and quite retarded hardware. 

The idea of using an old PC as a server has first occurred to me years ago. There is no reason to older then 2023, since the configs were ass, I don't remember half of the stuff and I never really used the server for anything back in those days. The only thing worth mentioning in the pre-2023 setup, is the fact that a Valheim server once fried the north bridge in my MSI 990FXA which is quite funny. 

At the end of 2023 I have finally decided to upgrade from my r7 2700 + gtx 1070 to something newer, and hence we get the new server from the old PC parts. The old build was in NZXT h200, so a decision was made to buy something more fitting for a server. I settled on Node 304 initially. But eventually moved the server into a Fractal Terra, since it's smaller and therefore easier to travel with.
